{{ sec('g-start','box-arrow-in-right', ar and 'الدخول والأدوار' or 'Login & roles') }} {% if ar %}
  • سجّل الدخول باسم المستخدم وكلمة المرور. كل مستخدم له دور يحدد الأقسام المتاحة له.
  • المدير يقدر يضيف/يعدّل الأدوار من المستخدمين ← إدارة الأدوار، ويضيف مستخدمين جدد.
  • تقدر تبدّل اللغة (عربي/إنجليزي) من الشريط العلوي.
{% else %}
  • Sign in with your username and password. Each user has a role that controls which sections they see.
  • Admins manage roles under Users → Manage roles and add new users.
  • Switch language (Arabic/English) from the top bar.
{% endif %} {{ sec('g-patients','people', ar and 'المرضى والاستيراد' or 'Patients & import') }} {% if ar %}
  • إضافة مريض: المرضى ← «مريض جديد». الأخوة بيترابطوا تلقائياً تحت نفس «اسم العائلة».
  • استيراد جماعي: المرضى ← «استيراد» ← نزّل القالب (Excel/CSV) واملأه وارفعه. بعد الرفع تظهر معاينة (الصفوف الصالحة والأخطاء) — مفيش حاجة تتحفظ إلا بعد ما تضغط «تأكيد الاستيراد».
  • ملف المريض: بياناته، التنبيهات الطبية، أولياء الأمور، الإخوة، الزيارات، النمو، التطعيمات، والتأمين.
{% else %}
  • Add patient: Patients → "New patient". Siblings are linked automatically under the same family name.
  • Bulk import: Patients → "Import" → download the template, fill it and upload. A preview shows valid rows and errors; nothing is saved until you confirm.
  • Patient profile: details, medical alerts, guardians, siblings, visits, growth, vaccinations and insurance.
{% endif %} {{ sec('g-coverage','shield-check', ar and 'التأمين والعضوية' or 'Insurance & membership') }} {% if ar %}
  • من ملف المريض ← تبويب العائلة ← التأمين: اختر الجهة + اكتب رقم الكارت وتاريخ الصلاحية.
  • زر «طبّق نفس الجهة على الإخوة» يضيفها للإخوة (كل واحد بكارته الخاص).
  • أي فاتورة للعضو تطبّق التغطية تلقائياً لكل خدمة (حسب جدول التغطية للجهة)، والكارت المنتهي بينبّهك.
{% else %}
  • From Patient profile → Family tab → Insurance: pick the entity, enter the card number and expiry.
  • "Apply to siblings" adds it to siblings (each keeps its own card).
  • A member's invoice auto-applies coverage per service; an expired card is flagged.
{% endif %} {{ sec('g-appts','calendar-week', ar and 'المواعيد والدور' or 'Appointments & queue') }} {% if ar %}
  • لوحة اليوم: المواعيد ← تتنقّل بين الأيام والأطباء، وتغيّر حالة كل موعد (منتظر/جاري/مكتمل/لم يحضر).
  • الدور: الأدمن يحدد من الإعدادات الترتيب «بالدور (رقم)» أو «بالتوقيت المحجوز».
  • زر واتساب على الموعد يبعت للمريض تأكيد بالموعد ورقم الدور.
{% else %}
  • Daily board: Appointments → navigate days/doctors and change each appointment's status.
  • Queue: admins choose "by queue number" or "by booked time" in Settings.
  • The WhatsApp button sends the patient a confirmation with their queue number.
{% endif %} {{ sec('g-clinical','clipboard2-pulse', ar and 'الزيارات والنمو والتطعيمات' or 'Visits, growth & vaccines') }} {% if ar %}
  • الزيارة: تبدأ من الموعد أو ملف المريض — العلامات الحيوية، التشخيص، الملاحظات، وطباعة الملخص.
  • النمو: منحنيات الطول/الوزن/محيط الرأس حسب مرجع منظمة الصحة العالمية.
  • التطعيمات: الجدول حسب العمر، تسجيل الجرعات، وشهادة تطعيم قابلة للطباعة. الإدارة من «إدارة التطعيمات».
{% else %}
  • Visit: start from an appointment or the patient file — vitals, diagnosis, notes and a printable summary.
  • Growth: height/weight/head-circumference curves against the WHO reference.
  • Vaccinations: age-based schedule, dose recording and a printable certificate.
{% endif %} {{ sec('g-inventory','box-seam', ar and 'المخزون والموردين' or 'Inventory & suppliers') }} {% if ar %}
  • المخزون: دفعات (لوط) بتاريخ صلاحية وكميات + تنبيهات (قرب الانتهاء/مخزون منخفض/نفاد).
  • عند تسجيل تطعيم اختياري بالعيادة يتخصم من المخزن تلقائياً (الأقرب انتهاءً أولاً).
  • الموردون: تضيفهم وتربط الدفعات بيهم.
{% else %}
  • Inventory: lot batches with expiry and quantities + alerts (near-expiry/low/out of stock).
  • Clinic-administered doses deduct stock automatically (first-expiry-first-out).
  • Suppliers: add them and link batches.
{% endif %} {{ sec('g-services','cash-stack', ar and 'الخدمات والعمولات' or 'Services & commissions') }} {% if ar %}
  • المالية ← الخدمات والعمولات: أضِف خدمات العيادة (سعر، أقصى خصم، كود).
  • لكل خدمة عمولة طبيب (نسبة أو مبلغ)، وتقدر تخصّص نسبة مختلفة لكل طبيب.
  • تقدر تعمل خدمة مجمّعة (مثلاً حجز + رسم تطعيم).
{% else %}
  • Finance → Services & commissions: add clinic services (price, max discount, code).
  • Each service has a doctor commission (percent or fixed), overridable per doctor.
  • You can build a bundle (e.g. booking + vaccination fee).
{% endif %} {{ sec('g-invoices','receipt', ar and 'الفواتير والدفعات' or 'Invoices & payments') }} {% if ar %}
  • المالية ← الفواتير ← فاتورة جديدة: اختر المريض والطبيب وأضِف البنود.
  • الحالة تلقائية: مدفوعة/جزئية/غير مدفوعة، وتقدر تسجّل دفعات جزئية.
  • تقدر تعدّل الفاتورة وبنودها بعد الإنشاء، وتطبعها.
  • زر «إنشاء فاتورة» موجود كمان في شاشة الزيارة.
{% else %}
  • Finance → Invoices → New invoice: pick patient and doctor, add line items.
  • Status is automatic: paid/partial/unpaid, with partial payments.
  • You can edit the invoice and its lines after creation, and print it.
  • A "Create invoice" button is also on the visit screen.
{% endif %} {{ sec('g-statements','person-badge', ar and 'كشف حساب الطبيب' or 'Doctor statement') }} {% if ar %}
  • المالية ← كشف حساب الطبيب: اختر الطبيب والفترة → يظهر نصيبه من كل الفواتير.
  • خيار «المدفوعة فقط» للتسوية على المُحصّل. الكشف قابل للطباعة.
{% else %}
  • Finance → Doctor statement: pick a doctor and period → see their share across invoices.
  • "Paid only" settles on collected amounts. The statement is printable.
{% endif %} {{ sec('g-claims','file-earmark-medical', ar and 'مطالبات الخصم' or 'Discount claims') }} {% if ar %}
  • المالية ← مطالبات الخصم ← إدارة الجهات: أضِف نادي/نقابة/تأمين، وحدّد جدول التغطية لكل خدمة.
  • الخصم الممنوح للعضو يبقى مستحقاً على الجهة، وتطبع مطالبة بالفترة لكل جهة.
{% else %}
  • Finance → Discount claims → Manage entities: add a club/syndicate/insurer and set the per-service benefits table.
  • The member's discount becomes claimable from the entity; print a per-entity claim for a period.
{% endif %} {{ sec('g-whatsapp','whatsapp', 'WhatsApp') }} {% if ar %}
  • الإعدادات ← واتساب: اختر طريقة الإرسال (واتساب ويب بضغطة / Cloud API / WaPilot)، وعدّل قوالب الرسائل.
  • الرسائل ← جدول اليوم: اختر الطبيب واليوم → «إرسال الجدول للطبيب» أو «إخطار كل المرضى».
  • كل رسالة تتسجّل في سجل الرسائل.
{% else %}
  • Settings → WhatsApp: choose the delivery method (Web link / Cloud API / WaPilot) and edit message templates.
  • Messages → Today's roster: pick a doctor and day → "Send schedule to doctor" or "Notify all patients".
  • Every message is recorded in the log.
{% endif %} {{ sec('g-eta','receipt-cutoff', ar and 'الفاتورة الإلكترونية (مصلحة الضرائب)' or 'E-invoicing (Tax Authority)') }} {% if ar %}
  1. على بوابة الضرائب: ملف الممول ← المفوضين ← تسجيل ERP → انسخ Client ID والمفتاح السري.
  2. في النظام: الإعدادات ← الفاتورة الإلكترونية → فعّل الربط، اختر الوضع، والصق البيانات وبيانات المنشأة (الرقم الضريبي/كود النشاط).
  3. لكل خدمة حدّد نوع التكويد (EGS/GS1) والكود (من شاشة الخدمات).
  4. على الفاتورة اضغط «تحويل لفاتورة ضريبية» → تدخل طابور الإرسال.
  5. المالية ← الفاتورة الإلكترونية → «إرسال» → تظهر الحالة (مقبولة/مرفوضة) مع UUID ورابط البوابة.
  6. الوضع التجريبي يحاكي المنظومة بدون اعتمادات — للعرض. الوضع الحقيقي يحتاج بياناتك وخدمة التوقيع (eSeal).
{% else %}
  1. On the ETA portal: Taxpayer profile → Delegates → Register ERP → copy the Client ID and secret.
  2. In the app: Settings → E-invoicing → enable, choose the mode, paste credentials and company data.
  3. Set each service's item type (EGS/GS1) and code (Services screen).
  4. On an invoice click "Make tax invoice" → it enters the submission queue.
  5. Finance → E-invoicing → "Send" → status shows (Accepted/Rejected) with UUID and portal link.
  6. Demo mode simulates the portal with no credentials. Live mode needs your data and a signing (eSeal) service.
{% endif %} {{ sec('g-settings','gear', ar and 'الإعدادات وأدوات البيانات' or 'Settings & data tools') }} {% if ar %}
  • الإعدادات: بيانات العيادة، رفع الشعار وإظهاره في الدخول/المطبوعات.
  • أدوات البيانات (للمدير): «تحميل بيانات تجريبية» للعرض، ومنطقة الخطر لمسح كل البيانات (تتطلب كتابة DELETE).
  • المستخدمون والأدوار: إضافة مستخدمين وتعديل صلاحيات الأدوار.
{% else %}
  • Settings: clinic details, upload the logo and show it on login/printouts.
  • Data tools (admin): "Load demo data" for presentations, and a danger zone to wipe all data (type DELETE).
  • Users & roles: add users and edit role permissions.
{% endif %}
