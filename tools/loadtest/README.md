# اختبار الحِمل والضغط — `tools/loadtest`

بند ١٥ في `IMPROVEMENTS_BACKLOG.md`. بيشغّل **سيرفر العيادة نفسه** (waitress،
إعدادات الإنتاج) على **نسخة متخيّلة**، ويبعت له ناس بتشتغل يوم عادي، وبعدين
بيكبّر لحد ما يقع — علشان نعرف **بيقع إزاي**.

## الخط الأحمر

**عمره ما يتوجّه على قاعدة عيادة شغّالة.**

- `fake_clinic` بيبني **ملف جديد بس**: بيرفض ملف موجود، وبيرفض المسار اللي
  `DATABASE_URL` أو `clinic.env` بيشاور عليه.
- وبيختم النسخة (`Setting load_test_copy = 1`).
- و`drive` بيرفض أي قاعدة مش مختومة.

## التشغيل

```bash
# ١) عيادة متخيّلة عمرها سنتين: ٨٠٠٠ طفل، ٣٢٠٠٠ زيارة وفاتورة، و١٢٠ ميعاد النهارده
python -m tools.loadtest.fake_clinic loadtest.db --patients 8000

# ٢) يوم شغل، وبعدين ×٢ ×٤ … لحد ما يقع
python -m tools.loadtest.drive loadtest.db --out results/ \
    --stages 1,2,4,8,16 --stage-seconds 60 \
    [--threads 8] [--busy-ms 15000]
```

النتيجة في `results/results.json`، ولوج السيرفر في `results/server.log`.

## مين بيشتغل

كل واحد من جهازه (عنوان لوحده)، وبالوقت اللي إنسان بياخده بين ضغطة والتانية:

| الدور | العدد في المرحلة ١ | بيعمل إيه |
|---|---|---|
| استقبال | ٢ | يدوّر على طفل · يسجّل طفل جديد · يحجزه كشف فوري · يبص على اليوم |
| طبيب | ٣ | ياخد الطفل اللي عليه الدور · يفتح الزيارة · يكتبها · يكتب دوا · يخرّجه |
| كاشير | ١ | ياخد اللي الطبيب خرّجه ويحصّل |
| شاشة الحائط | ٢ | تسأل كل ١٠ ثواني |

كل مرحلة بعدها بتضاعف الكل. الاختبار بيقف لما أبطأ ٥٪ من الردود تعدّي
`--give-up-p95` ثانية (١٠ افتراضياً) أو لما أكتر من ٥٪ يفشلوا.

## بعد ما يخلص: هل حاجة اتكتبت بالنص؟

كل حاجة الشاشة قالت عليها «تم» بتتراجع في القاعدة:

- كل حجز → حجز موجود.
- كل طفل اتسجّل → موجود.
- كل زيارة ودوا → موجودين زي ما الطبيب سابهم.
- كل تحصيل → فاتورة بسطورها، والفلوس قد السطور، **ومش مرتين**، وقيد يومية
  لو المحاسبة شغّالة.

## أرقام فيها افتراض لازم يتقال

- **بوابة الوردية مقفولة في النسخة** (`require_shift_to_collect = 0`). الاختبار
  بيقيس القاعدة تحت الحِمل مش الدرج.
- **السيرفر بتاع الاختبار بس** بيصدّق العنوان اللي كل واحد بيبعته
  (`X-Forwarded-For`)، علشان الحد بتاع الدخول يشوف ستاشر جهاز زي العيادة.
  سيرفر العيادة (`run.py`) ما بيصدّقش أي بروكسي، وwaitress بيشيل الهيدر ده.
- **الجهاز اللي بيتقاس عليه مش جهاز العيادة.** الأرقام بتتقارن ببعضها (قبل
  وبعد، خيوط أكتر أو أقل)، مش بتتنقل زي ما هي لجهاز تاني.
