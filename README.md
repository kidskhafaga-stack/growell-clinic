# 🏥 GROWELL CLINIC

نظام إدارة عيادة أطفال متكامل — احترافي، ثنائي اللغة (عربي / إنجليزي).

> An integrated pediatric clinic management system — professional and fully
> bilingual (Arabic / English) from day one.

---

## ✅ المراحل المكتملة

### المرحلة 1 — الأساس (Phase 1: Foundation)

- **هيكل المشروع** — تطبيق Flask منظّم (Application Factory + Blueprints).
- **قاعدة البيانات** — SQLite عبر SQLAlchemy، قابلة للترقية إلى PostgreSQL بتغيير `DATABASE_URL` فقط.
- **نظام الترجمة (i18n)** — كل النصوص عبر مفاتيح ترجمة في ملفات JSON، تبديل فوري بين العربية/الإنجليزية مع دعم RTL/LTR.
- **تسجيل الدخول** — مصادقة آمنة (تجزئة كلمات المرور)، "تذكرني"، وسجل دخول/خروج.
- **الصلاحيات** — 5 أدوار (مدير / طبيب / استقبال / محاسب / صيدلية) مع مصفوفة وصول لكل وحدة.
- **إدارة المستخدمين** — إضافة/تعديل/حذف (للمدير فقط).
- **الثيم الأخضر الطبي** — سايدبار بتدرّج لوني + لوحة تحكم تعرض الوحدات المتاحة حسب الدور.
- **سجل النشاط** + **إعدادات النظام** + **صفحات الأخطاء** (403/404/500).

### المرحلة 4 — الزيارة والفحص (Phase 4: Visit / Examination)

- **سجل الزيارة** — يُبدأ من ملف المريض أو من شاشة المواعيد (المريض الحالي → تسجيل الزيارة)، وعند إنهائه يُغلق الموعد المرتبط تلقائياً.
- **العلامات الحيوية** — الوزن، الطول، محيط الرأس، الحرارة، النبض، التنفس، تشبّع الأكسجين، مع حساب **BMI** فوري. الوزن/الطول/الرأس تُسجَّل تلقائياً في **مخطط النمو** (`growth_records`) جاهزة للمرحلة 5.
- **البيانات السريرية** — الشكوى الرئيسية + الفحص السريري + الخطة العلاجية + ملاحظات.
- **التشخيص ICD-10/11** — بحث فوري في قاعدة أكواد ICD-10 المدمجة (بالاسم أو الكود، عربي/إنجليزي) مع إكمال تلقائي، وتصنيف التشخيص: **أولي / ثانوي / نهائي**. الـ ICD-11 وأي كود خارج القائمة يُدخل يدوياً مع اختيار الإصدار.
- **ملخص الزيارة القابل للطباعة** + تبويب الزيارات في ملف المريض + قائمة أحدث الزيارات.

### المرحلة 5 — مخططات النمو (Phase 5: Growth Charts)

- **مراجع رسمية حقيقية** — جداول WHO (0-5 سنوات) و CDC (2-20 سنة) بقيم LMS الرسمية (مُولّدة من حزمة pygrowup، مدمجة في `app/data/growth/`). الطبيب يبدّل بين المراجع.
- **حساب Percentile و Z-score** بطريقة LMS (Cole) للوزن/الطول/محيط الرأس/BMI، منفصلة للذكور والإناث، مع استيفاء خطّي بين الأعمار. (تم التحقق من دقة الحسابات مقابل قيم WHO المرجعية.)
- **منحنيات تفاعلية (Chart.js)** — خطوط المئينات (P3/P15/P50/P85/P97) فوقها نقاط الطفل ومسار نموه، مع tooltip يعرض القيمة والمئيني والـ Z-score.
- **تنبيه الانحراف** — حالة بصرية (طبيعي / انتباه ±2 / تنبيه ±3) لأحدث قياس.
- القياسات تُجمع تلقائياً من الزيارات + إمكانية الإضافة اليدوية. لا تُرسم القياسات خارج نطاق عمر المرجع.

> RCPCH و WHO 5-19 يمكن إضافتهما لاحقاً بنفس آلية البيانات المدمجة.

### المرحلة 6 (جزء 1) — التطعيمات (Phase 6.1: Vaccinations)

- **تفريق إلزامي/اختياري** — التطعيمات الإلزامية (تُعطى في الصحة) يسجّلها الطبيب فقط لاكتمال الصورة؛ التطعيمات الاختيارية يوفّرها الطبيب بماركاتها وأسعارها.
- **جدول التطعيمات المصري** (قابل للتعديل) مُحمّل من `app/data/egypt_vaccines.json`.
- **نظام الماركات** — مثال فيروس الروتا: `RotaRix` (جرعتان) / `RotaTeq` (3 جرعات)، كل ماركة بجدول جرعاتها وسعرها. **منع خلط الماركات** — أول جرعة تُثبّت الماركة.
- **حالات بصرية** لكل جرعة: ✅ تم / ⚠️ مستحق / 🔴 متأخر / 📅 قادم، مع **اقتراح الجرعة القادمة** حسب عمر الطفل.
- **تسجيل الجرعات** (مع رقم اللوط + التاريخ الفعلي مقابل الميعاد المتوقّع) + **شهادة تطعيم قابلة للطباعة** + تبويب التطعيمات في ملف المريض.
- **إدارة التطعيمات** — الطبيب يضيف/يعدّل تطعيمات وماركات وجداول جرعات، ويختار إلزامي/اختياري.
- **ترقيم الصفحات (Pagination)** — كل القوائم الطويلة (المرضى/الزيارات/التطعيمات/النمو) مقسّمة 25 لكل صفحة (server-side) — سريعة مع آلاف الحالات.

> الجزء 2 من المرحلة 6 (مخزون التطعيمات + الموردين) قادم.

### المرحلة 3 — المواعيد والجدول الذكي (Phase 3: Appointments)

- **شاشة الطبيب "Today's Appointments"** — التصميم المرجعي: 4 كروت إحصائية ملوّنة (إجمالي/مكتمل/انتظار/لم يحضر)، بطاقة المريض الحالي بـ 3 أعمدة، وجدول مواعيد اليوم بحالات ملوّنة وأزرار إجراء لكل حالة.
- **جدول عمل الأطباء** — فترات عمل لكل يوم (من/إلى)، مدة الموعد، أقصى عدد مرضى، تعدّد الفترات (صباحي/مسائي).
- **الحجز الذكي** — توليد الأوقات المتاحة فقط من جدول الطبيب (تحميل فوري عبر AJAX) + **منع التعارض** (لا يمكن حجز نفس الوقت مرتين، تحقّق على الخادم أيضاً) + تخطّي الأوقات الماضية.
- **دورة حياة الموعد** — مجدول → في الانتظار → في الكشف → مكتمل / لم يحضر / ملغي، مع حفظ توقيتات كل مرحلة ومنع الانتقالات غير الصحيحة.
- **تنقّل التواريخ** (السابق/اليوم/التالي) + فلتر الطبيب.

### المرحلة 2 — المرضى والأسر (Phase 2: Patients & Families)

- **ملفات المرضى** — إضافة/تعديل/حذف، بحث، وإحصائيات حية (إجمالي/نشط/ذكور/إناث).
- **نظام الرقمين** — رقم نظام تلقائي مكوّد (`PM-YYYY-NNNN` سنوي أو `GC-NNNNNN` ثابت، قابل للاختيار من الإعدادات) + **رقم ملف مرجعي** للرقم الورقي القديم (قابل للبحث).
- **الاستيراد بالجملة (Bulk Import)** — رفع بيانات المرضى القدامى من Excel (.xlsx) أو CSV، مع قالب جاهز للتحميل، ربط الأخوة تلقائياً باسم الأسرة، إنشاء أولياء الأمور، وتقرير بالنتيجة (نجاح/تخطّي مع الأسباب).
- **بيانات كاملة** — الاسم (عربي/إنجليزي)، تاريخ الميلاد + حساب العمر، الجنس، الرقم القومي، فصيلة الدم، والصورة (رفع + معاينة).
- **التنبيهات الطبية** — الحساسية والأمراض المزمنة بارزة في رأس الملف.
- **الأسرة** — ربط الأب/الأم/أولياء الأمور + الأخوة على نفس الأسرة، مع فئة العميل (عادي/صديق/قريب/موظف) للخصومات لاحقاً.
- **ملف المريض الاحترافي بالتبويبات** — نظرة عامة / الأسرة / الزيارات / النمو / التطعيمات / الروشتات / المستندات / المالي (التبويبات اللاحقة محجوزة للمراحل القادمة).
- **واجهة متحركة وتفاعلية** — طبقة أنيميشن مشتركة (Alpine.js + CSS): تبويبات سلسة، نوافذ منبثقة، أرقام متحركة، ظهور تدريجي، hover/ripple، واحترام `prefers-reduced-motion`.

## 🚀 التشغيل (Getting started)

### تشغيل بضغطة واحدة (Windows)
شغّل ملف **`start.bat`** — يسطّب كل المتطلبات تلقائياً، يهيّئ قاعدة البيانات في أول مرة، ويفتح البرنامج في المتصفح. (على Linux/macOS استخدم `./start.sh`.)

### يدوياً

```bash
# 1) إنشاء بيئة افتراضية وتثبيت الاعتماديات
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt

# 2) (اختياري) ضبط متغيرات البيئة
cp .env.example .env

# 3) تهيئة قاعدة البيانات + إنشاء مستخدمين تجريبيين
flask --app run seed

# 4) التشغيل
python run.py
# ثم افتح http://localhost:5000
```

### أوامر CLI

```bash
flask --app run init-db        # إنشاء الجداول + الإعدادات الافتراضية
flask --app run seed           # مستخدمون تجريبيون (واحد لكل دور)
flask --app run create-admin   # إنشاء حساب مدير تفاعلياً
```
